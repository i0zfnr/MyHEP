SUMMARY
-------
StudentEdge is a Laravel 13 student-affairs application covering student profiles,
scholarship, discipline, fines, vehicle stickers, announcements, campus movement,
private documents, notifications, reports, administration, and system controls.

CURRENT IMPLEMENTATION
----------------------
- Custom student/admin session authentication with password reset and linked role mode.
- Active device/session tracking through account_sessions. Users can revoke one other
  session or every other session from Settings.
- Central AdminPermissions abilities. Guard can list/search students but cannot view
  sensitive detail, export, create, edit, delete, import, or reset passwords.
- IC numbers are masked outside sensitive-detail contexts.
- Private student_documents disk and metadata table. Students download only their own
  documents; Head of Student Affairs and System Admin can review and download them.
- Scholarship declarations can upload a private offer letter linked to the document
  workflow. Replacing/removing metadata also handles the stored file.
- System Admin can enable/disable document_centre; middleware enforces the state.
- Admin profile photo upload supports browser crop, zoom, rotate, reset, and preview.
- Movement feed uses cursor batches and bounded DOM virtualization. Lenis smooths
  mouse-wheel scrolling while touch and nested interactive regions stay native.
- PWA install prompts appear only on student/admin dashboards.
