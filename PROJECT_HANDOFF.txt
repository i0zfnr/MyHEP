3. Program reports are drafts until a human checks content, formatting, blank pages, images, names, dates, and signatures.

5. Update both lang/en.json and lang/ms.json for every user-visible workflow change.
6. Preserve native nested scrolling in dialogs, tables, scanners, and file drop zones.
7. Run `php artisan view:clear`, `php artisan test`, and `npm run build` before release.
